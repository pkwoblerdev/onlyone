# Обновления через GitHub Releases

Начиная с 1.3.39, установленная Windows-версия проверяет выпуски `pkwoblerdev/onlyone` на GitHub. Найденное обновление скачивается и устанавливается при выходе из приложения, если автоматические обновления включены в настройках. Настройка пользователя об отключении сохраняется. Portable-версия не запускает установщик и обновляется отдельно.

Сохранённые адреса прежних сторонних серверов не используются. Если пользователь явно настроил собственный HTTPS-адрес обновлений, его можно проверять вручную; автоматическая установка ограничена официальным каналом GitHub.

## Подготовка следующего выпуска

1. Увеличить версию приложения и собрать Windows-установщик с настройками `electron-builder.config.cjs`.
2. В GitHub Releases создать выпуск с тегом, соответствующим версии, и прикрепить **установщик `.exe` и `latest.yml` из одной сборки**. Имена файлов и содержимое `latest.yml` менять нельзя.
3. Также можно прикрепить `.exe.blockmap`: он позволяет оптимизировать скачивание. Portable-файл можно публиковать отдельно, но он не заменяет установщик для автообновления.
4. Проверить загрузку опубликованных файлов и обновление предыдущей установленной версии в отдельной среде. Проверить, что профиль и чаты сохранились.

Проект использует и pre-release выпуски. Репозиторий и опубликованные файлы должны быть доступны пользователям без личного токена. Для текущего выпуска 1.3.38 автоматическое обновление отключено, поэтому переход на 1.3.39 выполняется ручной установкой один раз.

Сборки пока не подписаны цифровой подписью. SHA-512 в `latest.yml` проверяет целостность скачанного файла относительно метаданных, но не заменяет подпись издателя. Перед публикацией и автоматической установкой необходимо защищать доступ к аккаунту GitHub и проверять содержимое выпуска.
