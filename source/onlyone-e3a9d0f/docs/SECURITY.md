# Security / Безопасность

A verified private reporting channel has not yet been established. Do not publish sensitive vulnerability details or credentials in a public issue. The maintainer will add a private contact before public distribution.

Проверенный закрытый канал сообщений об уязвимостях пока не настроен. Не размещайте чувствительные сведения об уязвимостях и ключи в открытых обращениях. До публичного распространения проекта владелец добавит закрытый контакт.
