# Releases / Выпуски

Installers and portable builds are not stored in the Git repository. When available, download them from the repository's [Releases page](https://github.com/pkwoblerdev/onlyone/releases).

The 1.3.38 candidate was built from source revision `4c4c5c3`. Its Windows executables are unsigned. See the [release status](../docs/RELEASE-STATUS.md) for verification and remaining limitations.

Установщики и portable-сборки не хранятся в Git-репозитории. После публикации их можно скачать на странице [Releases](https://github.com/pkwoblerdev/onlyone/releases).

Кандидат 1.3.38 собран из ревизии `4c4c5c3`. Исполняемые файлы Windows не подписаны. Проверки и оставшиеся ограничения описаны в [статусе выпуска](../docs/RELEASE-STATUS.md).
