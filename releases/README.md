# Releases / Выпуски

Installers and portable builds are not stored in the Git repository. When available, download them from the repository's [Releases page](https://github.com/pkwoblerdev/onlyone/releases).

The 1.3.39 candidate was built from source revision `e3a9d0f`. Installed Windows builds check GitHub Releases using `latest.yml` and `onlyone-Setup-1.3.39.exe` from the same build; version 1.3.38 requires a one-time manual install to switch to 1.3.39. Its Windows executables are unsigned. See the [release status](../docs/RELEASE-STATUS.md) and [GitHub updates](../docs/GITHUB-UPDATES.md) for verification and remaining limitations.

Установщики и portable-сборки не хранятся в Git-репозитории. После публикации их можно скачать на странице [Releases](https://github.com/pkwoblerdev/onlyone/releases).

Кандидат 1.3.39 собран из ревизии `e3a9d0f`. Установленная Windows-версия проверяет обновления через GitHub Releases при наличии `latest.yml` и `onlyone-Setup-1.3.39.exe` из одной сборки; переход с 1.3.38 выполняется ручной установкой один раз. Исполняемые файлы Windows не подписаны. Проверки и оставшиеся ограничения описаны в [статусе выпуска](../docs/RELEASE-STATUS.md) и [инструкции по обновлениям](../docs/GITHUB-UPDATES.md).

Portable archives contain the standalone portable executable; extract the archive before running it. Portable builds do not install updates automatically. / Архив portable содержит отдельный исполняемый файл; перед запуском распакуйте архив. Portable-версия не устанавливает обновления автоматически.
